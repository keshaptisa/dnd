# AI DnD Master

Проект, созданный в рамках хакатона `AI Arrow`: прототип AI-ведущего для `Dungeons & Dragons`, который помогает запускать и вести текстово-голосовую игровую сессию в Telegram.

Бот берет на себя часть функций мастера игры:

- знакомит игроков с правилами старта;
- принимает персонажей в виде анкет;
- определяет очередность ходов через броски кубика;
- генерирует начало и продолжение истории;
- интерпретирует действия игроков;
- создает иллюстрации к сценам;
- поддерживает текстовый и голосовой формат взаимодействия.

## Идея проекта

Во многих настольных ролевых играх игрокам нужен человек-ведущий, который управляет сюжетом, описывает сцены, реагирует на действия героев и следит за ходом игры.
Этот проект исследует, можно ли передать часть этой роли AI-системе и превратить Telegram-бота в интерактивного цифрового мастера для DnD-сессии.

## Что умеет бот

- Запускает сессию через Telegram-интерфейс.
- Дает выбор между `текстовым` и `аудио` форматом общения.
- Принимает CSV-файлы с данными персонажей.
- Создает игровую очередь через броски `d20`.
- Генерирует вступление к приключению с помощью LLM.
- Обрабатывает действия игроков и превращает их в сюжетные последствия.
- Проверяет действия через игровую механику с характеристиками персонажа и случайным броском.
- Генерирует изображения сцен по ходу истории.
- Поддерживает голосовой ввод действий игроков.
- Преобразует текст истории в аудио-ответы.

## Как устроен сценарий игры

1. Игрок выбирает формат взаимодействия: текст или аудио.
2. Бот отправляет инструкцию и предлагает загрузить анкеты персонажей.
3. Данные персонажей подгружаются из CSV-файлов.
4. Игроки бросают кубик, и бот формирует порядок ходов.
5. После старта игры AI генерирует завязку истории.
6. Каждый игрок отправляет действие текстом или голосом.
7. Бот:
   - выбирает проверяемую характеристику;
   - генерирует порог сложности;
   - делает бросок `d20`;
   - определяет успех или неудачу;
   - просит модель описать последствия действия;
   - при необходимости создает изображение сцены.
8. После круга ходов бот продолжает сюжет.

## Основные возможности AI-части

### 1. Генерация сюжета

Для генерации вступления и последующих сюжетных событий используется LLM через OpenAI API.

Бот умеет:

- генерировать начало приключения;
- продолжать историю после действий игроков;
- создавать реакцию мира на успех или провал персонажа.

### 2. Генерация изображений

Проект использует генерацию изображений по текстовому описанию сцены.

Это позволяет:

- визуализировать стартовую сцену;
- сопровождать игровые события иллюстрациями;
- усиливать эффект погружения в приключение.

### 3. Голосовое взаимодействие

В проекте есть поддержка голосового режима:

- текст истории можно озвучивать;
- действия игрока можно отправлять голосом;
- голос преобразуется в текст через локальное распознавание речи.

## Игровая логика

В проекте реализована упрощенная RPG-механика:

- у персонажей есть характеристики:
  - сила
  - ловкость
  - телосложение
  - интеллект
  - мудрость
  - харизма
- для действия выбирается характеристика и порог сложности;
- затем выполняется бросок `d20`;
- итог определяется как сумма броска и значения характеристики;
- на основе результата AI описывает последствия действия.

Это делает игру не просто чат-ботом с генерацией текста, а прототипом AI-ведущего с элементами ролевой механики.
